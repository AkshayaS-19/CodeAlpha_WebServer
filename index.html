Deployment Workflow

From source code to a running container

01

Source Code

HTML source files and Docker configuration define the web application.

02

Build Image

Docker builds a reusable image containing NGINX and the web application.

03

Run Container

The Docker image is launched as an isolated running container.

04

Serve & Monitor

NGINX serves the webpage while Docker provides container monitoring and management.

This project demonstrates practical Docker-based web server deployment as part of the CodeAlpha DevOps Internship. The implementation covers containerization, image creation, port mapping, container lifecycle management, monitoring, troubleshooting and GitHub-based source code management.
